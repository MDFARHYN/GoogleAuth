Google Authenticator Desktop

1. OPEN SOURCE SOFTWARE NOTICE
Google Authenticator Desktop is free, open-source software provided under the MIT License. It is designed to provide local, decentralized two-factor authentication (2FA/TOTP) code generation directly on your personal computer.

2. LOCAL ENCRYPTED VAULT & ZERO TELEMETRY
This application operates completely offline and locally on your machine. All 2FA secret keys, provider accounts, and configuration data are stored in an encrypted local vault using AES-256-GCM authenticated encryption and Argon2id key derivation. No credentials, tokens, metadata, or telemetry are ever uploaded or transmitted to any remote cloud servers.
